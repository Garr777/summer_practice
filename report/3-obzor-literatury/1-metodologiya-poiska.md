Обзор выполнен по процедуре, близкой к методике систематического картирования
предметной области: поисковые запросы, критерии отбора и результаты каждого
этапа зафиксированы до вынесения содержательных суждений, что позволяет
воспроизвести и проверить выборку.

## 3.1.1. Источники данных

Поиск выполнялся программно через программные интерфейсы двух библиографических
служб, что исключает зависимость результата от персонализации выдачи
поисковых систем:

| Служба | Охват | Извлекаемые поля |
|---|---|---|
| Crossref REST API | рецензируемые журнальные и конференционные публикации, имеющие DOI | DOI, заглавие, авторы, издание, год, тип публикации |
| arXiv API | препринты по направлениям `cs.DC`, `cs.SE`, `cs.LG` | идентификатор arXiv, заглавие, авторы, дата, ссылка на журнальную версию |

Для источников, не индексируемых указанными службами, — нормативных правовых
актов Российской Федерации, отраслевых аналитических отчётов и документации
программных продуктов — применялся адресный поиск с проверкой по официальным
публикаторам.

## 3.1.2. Поисковые запросы

Набор из **26 запросов** сформирован по шести тематическим направлениям,
соответствующим кластерам таксономии
([раздел 3.2](2-taksonomiya.md)). Примеры запросов:

- `predicting resource consumption Kubernetes container systems`
- `quantile regression resource allocation SLA cloud`
- `vertical pod autoscaler resource recommendation`
- `CloudSim simulation framework cloud computing environments`
- `continuous integration build duration optimization empirical study`
- `continuous integration build failure prediction machine learning`
- `carbon aware scheduling datacenter`

Полный набор запросов, а также программа их выполнения приведены в каталоге
`research/` репозитория отчёта (`research/search.py`); повторный запуск
воспроизводит выборку и пересчитывает приведённую ниже воронку.

## 3.1.3. Критерии включения и исключения

**Критерии включения:**

1. год публикации — 2021 и позднее (окно 3–5 лет от момента подготовки отчёта);
2. тип публикации — статья в рецензируемом журнале, доклад конференции, глава
   монографии либо препринт признанного репозитория;
3. тематическая релевантность — работа относится хотя бы к одному из кластеров
   таксономии и рассматривает вычислительные ресурсы, планирование нагрузки,
   прогнозирование потребления, имитационное моделирование инфраструктуры или
   эмпирику конвейеров непрерывной интеграции;
4. проверяемость выходных данных — наличие DOI либо устойчивого идентификатора.

**Критерии исключения:**

1. издания, не осуществляющие содержательного рецензирования (в выдаче
   встречались публикации в журналах с признаками недобросовестной издательской
   практики; такие записи отклонялись независимо от релевантности заглавия);
2. работы, относящиеся к предметной области лишь терминологически (совпадение
   по ключевым словам при ином предмете исследования);
3. дубликаты — препринт и его журнальная версия учитывались как одна позиция;
4. учебные и справочные издания без исследовательского вклада.

## 3.1.4. Воронка отбора

Приведённые значения получены выполнением `research/search.py`; они
воспроизводимы и пересчитываются при повторном запуске.

| Этап | Количество записей |
|---|---|
| Извлечено по 26 запросам (с повторами) | 204 |
| Уникальных записей после дедупликации | 192 |
| Соответствуют критерию типа публикации | 170 |
| Опубликованы в 2021 г. и позднее | 119 |
| **Включено после содержательного отбора** | **37** |

Из 37 включённых научных источников **33** найдены основным набором запросов, а
**4** — дополнены методом «снежного кома», то есть адресным поиском по ссылкам
из уже отобранных работ; таким образом покрыты, в частности, русскоязычные
публикации [26], [37]. Соответствие включённых источников этапам отбора
зафиксировано в файле `research/included.txt`.

К 37 научным источникам добавлены 4 позиции кластера К7 — два нормативных
правовых акта [38], [39], отраслевой аналитический отчёт [40] и документация
программного продукта [41], — привлечённые для обоснования актуальности
([раздел 2.2](../2-problematika/2-aktualnost.md)) и описания инструментальной
базы. Итоговый объём перечня — **41 позиция**, что превышает требуемый минимум
в 30 источников.
